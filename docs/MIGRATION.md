# Migrating to the English API

The published `0.1.0a2` alpha intentionally renames the public interfaces for international reuse. It is not the future canonical v2 system. Transcription envelopes and documentary catalogues now use schema `0.2.0`.

## Commands, modules, and artifacts

| Previous interface | English interface |
| --- | --- |
| `herbarium_labels.briofitas` | `herbarium_labels.bryophytes` |
| `Etiqueta` in the bryophyte reader | `BryophyteReading` |
| `sennen.Etiqueta` / `sennen.Leitura` | `sennen.Label` / `sennen.SheetReading` |
| `transcrever` / `relatorio` / `lote` | `transcribe` / `report` / `batch` |
| `--fotos` / `--saida` | `--images` / `--output` |
| `--limite` / `--amostra` / `--sem-pdf` | `--limit` / `--sample` / `--no-pdf` |
| `transcricao/` | `transcription/` for new batch runs |
| `transcricoes_briofitas.xlsx` | `transcriptions.xlsx` |
| `conferencia_briofitas.pdf` | `review.pdf` |
| `transcricao_briofitas.zip` | `transcriptions.zip` |
| `fotos/` / `miniaturas/` in output | `images/` / `thumbnails/` |
| `Transcrição literal` / `Campos` worksheets | `Literal transcription` / `Fields` |

Old Python import and command names are not retained as aliases. Update callers before using the new alpha. `sennen.py` keeps the historical person's proper name and its collection-specific scope; it still receives a full sheet and lower crop.

## JSON keys

New output always uses English keys. The compatibility module accepts the following old keys when reading, returning a copy without rewriting the file or translating its values:

| Old key | English key |
| --- | --- |
| `ficheiro`, `modelo`, `segundos`, `leitura` | `filename`, `model`, `elapsed_seconds`, `reading` |
| `rotacao_para_ler`, `herbario`, `serie_colecao` | `rotation_degrees`, `herbarium`, `collection_series` |
| `nome_como_escrito`, `especie`, `autor`, `determinador` | `name_as_written`, `species`, `taxonomic_author`, `determiner` |
| `pais_provincia`, `localidade`, `ecologia` | `country_province`, `locality`, `ecology` |
| `data_como_escrita`, `data_iso`, `coletor`, `numero` | `date_as_written`, `date_iso`, `collector`, `collection_number` |
| `anotacoes_manuscritas`, `texto_literal`, `duvidas` | `handwritten_notes`, `literal_text`, `uncertainties` |
| `etiquetas`, `origem` | `labels`, `origin` |
| `numero_geral_po`, `numero_ordem`, `numero_exsiccata_sennen` | `general_accession_number`, `order_number`, `sennen_exsiccata_number` |
| `cota`, `nome_etiqueta_sennen`, `nome_etiqueta_porto`, `data_colheita` | `shelfmark`, `sennen_label_name`, `porto_label_name`, `collection_date` |

`altitude` and `utm` already have suitable names. Literal strings, line breaks, leading zeros, original-language uncertainty, and ambiguous dates are preserved. English field names never authorize translating the evidence or filling missing information.

For catalogues, `rascunho`/`revisado` are read as `draft`/`reviewed`; `candidata`/`confirmada`/`contestada` become `candidate`/`confirmed`/`contested`. Confirmation still requires samples, sources, evidence, and a reviewer. Historical names and IDs remain unchanged. No new aliases, characteristics, rights, or attributions were invented.

## Preserve previous work

- Keep original images and JSONs. `report --images ORIGINALS --output OLD_OUTPUT` reads compatible old JSON in memory and writes English reports; it does not rewrite the JSONs.
- A conflicting old/new key pair is rejected rather than silently choosing a value. Unknown schema versions and unexpected reading fields are rejected.
- Prompt/schema/codec changes invalidate cache identity. Do not reuse old results as if generated by the translated prompt; choose a new output directory for new transcription.
- Old `transcricao/` output directories are not renamed or imported automatically by `batch`. Its new `transcription/` path avoids overwriting them.
- The new lock is `.transcription.lock`; a present legacy lock also blocks a new run. Check for active processes before removing an abandoned lock.
- Human corrections remain valid evidence. A migration or new model run must not overwrite them to obtain fresh output.

See [TESTING.md](TESTING.md) for legacy-read regressions and [PROMPT_CHANGES.md](PROMPT_CHANGES.md) for the scientific evaluation boundary.

## Proposed 0.1.0a3 reuse contracts

The English API migration is already present in published 0.1.0a2. Its former patch is obsolete and removed. Version 0.1.0a3 is a new source proposal, not an update to the published tag.

Existing `bryophytes.transcribe/report/batch`, `sennen.read_labels`, and the default CLI remain available. New `--profile sennen` enables shared file deliveries. `read_image` accepts Python-defined profiles; see INTEGRATION.md.

Use `suggestions(..., field_map={"shelfmark": "cota"}, messages=host_renderer)` for Taxa. Do not rename canonical schema fields globally. `read_labels` accepts `options` and `request_context`. It no longer applies a global semaphore; hosts own request/user limits. `check_rate(user_id)` now requires `limiter=callback` and raises if missing, so an old host cannot silently lose its quota check.

The new shared image policy never upscales small images. Sennen still sends two views. Its prompt now describes the second image as a crop, removing only the word "enlarged". Other scientific prompt instructions and reading schemas are unchanged. The transform/profile cache identity changes deliberately; preserve old output and choose a fresh directory. Existing human corrections are never silently overwritten.

Pillow metadata permits 11.3 while the primary hashed lock remains 13. Functional compatibility is tested independently; this does not backport decoder security fixes. CLI `transcribe` returns status 1 when its summary contains failures.

## Folder API and explicit historical imports (0.1.0a3 follow-up)

The maintainer applied the preceding reuse patch and reported 61 passing tests plus three matching Taxa suggestion scenarios. The incremental follow-up adds plain path-based folder APIs, profile registration/installed entry points, report translations, explicit prices, consistent retry defaults, and `--accept-existing`. The version stays at the unreleased 0.1.0a3 target; no publication of that version is claimed.

Existing namespace adapters and `herbarium_labels.suggestions` imports remain available. The implementation is now explicitly named `sennen_suggestions`. Pass the same `options` to reading and Sennen suggestion rendering to display the correct model.

Strict cache identity checks remain the default. `--accept-existing` records a deliberate historical import in `.accepted-existing.json`, preserves every original JSON byte, and does not assign new pipeline provenance. It validates the whole batch, blocks known source mismatches, and marks absent historical image hashes as unverified. Keep the ledger with source images and JSON. No existing research directory is migrated automatically.
